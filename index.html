典型二阶系统的单位阶跃响应

标准形式 G(s) = K·ωn² / ( s² + 2ζωns + ωn² )。拖动滑块观察响应与动态指标的变化，体会 ζ 与 ωn 的作用。

判读：ζ<1 欠阻尼（振荡+超调）；ζ=1 临界阻尼（无超调最快）；ζ>1 过阻尼（迟缓无超调）。工程上常取 ζ≈0.707（最佳阻尼比）。

PID 控制器：三个参数各自做什么

Bode 图与稳定裕度

输入开环传递函数 G(s)=N(s)/D(s) 的系数（按 s 升幂、逗号分隔）。示例：N=4，D=4, 0.8, 1 即 4/(s²+0.8s+4)。

幅值裕度 h 在相频穿越 -180° 处读取（-|G| dB）；相角裕度 γ 在幅频穿越 0dB 处读取（180°+∠G）。两者同时为正是最小相位系统闭环稳定的判据。

Nyquist 图与稳定性判据

与 Bode 实验共用传递函数输入（改动后点「绘制」）。红叉为临界点 (-1, j0)，虚线圆为单位圆。

判据（最小相位系统）：曲线不包围 (-1, j0) ⇔ 闭环稳定。包围则闭环不稳定；恰好穿过则临界稳定。程序同时直接求解闭环特征方程根作交叉验证。

根轨迹：增益 K 从 0 → ∞ 的闭环极点运动

先选模式，然后在坐标区点击放置开环极点(×)/零点(○)。特征方程 D(s)+K·N(s)=0，K 对数扫掠，暖色对应大 K。

要点：根轨迹起于开环极点（K=0）、终于开环零点或无穷远（n>m 的分支沿渐近线发散）。轨迹全部位于左半平面 ⇔ 该 K 下闭环稳定。

Bode 裕度游乐场:拖零极点,看裕度实时变化

上图点击放置 / 拖动开环零极点(极点 ×、零点 ○;Shift+点击放共轭对;「删除模式」点标记移除,共轭对成对删)。开环 L(s) = K·∏(s−zi) / ∏(s−pj),拖 K 滑块,下方 Bode 图与裕度立即重算。

看点:把一个极点拖向虚轴,相位在更低频就开始下坠,γ 被一口口吃掉;加一个零点(放在极点左边)相当于 PD/超前补偿,γ 回血——教材第 7、8 章的几何直觉,这里是它的频域版本。

Nyquist 围线动画:D 形围线如何扫出幅相曲线

左:s 平面上的 D 形围线(沿 jω 轴自 −jR 上行,再经右半大半圆顺时针闭合),动画点沿围线巡游;右:映射点同步在 L 平面描出 Nyquist 曲线。围线内的开环极点信息,全部编码进「曲线绕 (−1, j0) 的圈数」。

圈数 N 由 arg(L+1) 沿围线的净变化除以 2π(顺时针为正),Z = N + P。默认示例即教材例 6.1:L=12/((s+1)(s+2)(s+3));把 K 拖过 5,看曲线膨胀、穿过 −1 的瞬间——劳斯给出的临界增益 60 与之精确一致。

PID 救火箭:调 Kp/Ki/Kd,软着陆

火箭从 100 m 高空下落,推力 u = PID(高度误差)只能向上喷(0 ≤ u ≤ 30 m/s²),g = 9.8 m/s²。误差 e = −高度:Kp 催落(目标就是地面)、Kd 刹车保平安、Ki 在攒「催落」的账多半帮倒忙——滑块可以在下落途中实时拧!

评分:|v| < 1.5 m/s 完美着陆 ★★★;< 3 m/s 成功 ★★;< 6 m/s 硬着陆 ★(箭体损伤);再大就是烟花。挑战:先拖 Kd = 0 体验自由落体,再半路把它救回来。

采样与数字 PID:ZOH 离散闭环(教材第 13 章 · 实验 10)

对象 G(s) = 1/(s+1),零阶保持,采样周期 T。数字控制器 uk = Kpek + KiT·Σej(后向矩形积分;Ki = 0 即纯比例)。圆点为采样序列,灰虚线为同 Kp 的连续闭环对照,z 平面显示闭环极点。

读法:T=1、Kp=1 时序列应为 0.632 → 0.465 → 0.509…(教材例 13.1,「隔拍振铃」);闭环极点滑上负实轴 = 振铃,撞上单位圆 = 发散,Kc = (1+e−T)/(1−e−T)。数字 PI 的稳定域是三角形:Ki < (2/T)(Kc − Kp),对照教材例 13.2(Kp=1、T=1 时 Ki < 2.33)。
